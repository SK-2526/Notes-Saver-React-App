# Notes-Saver-React-App

🎯 Overview:
This React.js To-Do List app offers real-time task updates—as soon as a user adds, edits, deletes, or copies a task, the UI updates instantly without page refresh. It uses React's state management to re-render components dynamically, ensuring changes reflect immediately. 
Toast notifications provide real-time feedback for user actions, enhancing interactivity and responsiveness.

It's aimed at improving productivity by tracking tasks and providing a simple, clean UI for managing daily to-dos.So it captures and displays the real-time date and time when a task is added or updated. It uses JavaScript's Date object to dynamically fetch the current timestamp.
Also use Local Storage when page is refresh the etire data will not loss.


🛠️ Technologies Used:
React.js: For building UI components and managing state

CSS/Tailwind CSS : For styling the layout and elements

React Icons: For edit/delete/copy icons

React-Toastify or a similar library: For toast notifications
